What is this?

How far the ball travels each frame, in field units (the field is 800 wide). Range 2 to 10, default 5. Every paddle hit adds 3% up to double the base speed, and each serve starts over. The fly's reaction time is fixed by its wiring, about 8 brain milliseconds from seeing the ball to a descending command, so a faster ball gives it less time to line up. Around 3 it returns almost everything; around 8 it loses most rallies.

Bot
What is this?

Hands your paddle to a script. The bot follows the ball at a capped 4 units per frame while the ball is coming toward it, and drifts back to center otherwise. It is deliberately beatable: a steep angle off the fly's paddle can outrun it. Toggle with the checkbox or the B key, even mid-rally. Leave it on to train the fly unattended.

What is this?

Every time the fly returns the ball, its 316 PAM dopamine neurons are stimulated; every time it misses, its 16 PPL1 dopamine neurons are. These are the cells a real fly uses to signal reward and punishment. Their spikes travel down their real axons, rebuilt from the raw synapse counts, to the 8,599 neurons they actually innervate: almost every Kenyon cell and output neuron of the mushroom body, the fly's learning center, plus a few dozen descending neurons.

Meanwhile 4.36 million synapses keep an eligibility trace that rises when the sending cell fired just before the receiving cell and fades over 100 brain milliseconds. Each tick, every eligible synapse that received dopamine changes: reward strengthens it, punishment weakens it, scaled by the learning rate. A synapse never changes sign and stays between a tenth and four times its original strength.

Two things are ours, not the fly's. A weak diffuse dopamine signal also reaches the visual-projection-to-descending pathway that drives the paddle, because in this simplified model mushroom-body output cannot reach the escape neurons on its own; without it learning could never change play. And reward potentiates while punishment depresses, where the real mushroom body uses depression in both cases with the valence set by which output neuron is affected.

Learned weights are saved every minute and on shutdown, and reloaded when the server starts, so the fly keeps its memory across sessions. Forget everything restores the original connectome. The fly cannot learn a new direction of movement, that is fixed by its anatomy; what it can learn is how fast and how hard to react. Watch the return rate line to judge whether it does.

What is this?

How many one-millisecond brain steps run for each game frame. Range 1 to 16, default 4. The whole 166,700-neuron brain runs at roughly 80 steps per second on this Mac's GPU with learning on, so 4 gives about 20 brain updates per second and 16 gives about 5. More steps per frame means the fly gets more thinking time per frame, which sharpens its reactions, but the game updates its command less often. At the default, one second of game time is about 80 milliseconds of brain time.

What is this?

The voltage nudge given each step to the looming detectors on the eye facing the ball: 126 LC4 cells and 185 LPLC2 cells, the neurons a real fly uses to notice something rushing at it. The nudge is scaled by how close the ball is and how far it sits above or below the paddle, and cut to a quarter when the ball is moving away. Range 0 to 1, default 0.3. At 0 the fly is blind to the ball and the paddle never moves. High values fire the escape neurons on every approach and can make the paddle overshoot. This is the one input that actually reaches the descending neurons.

What is this?

The voltage nudge given to the fly's first visual neurons, the lamina cells L1, L2 and L3, in the eye columns where the ball's image lands (a 2-column radius, using the real eye-column coordinates from the dataset). You can watch it in the brain view as a small flare in the optic lobe that moves with the ball. Range 0 to 1, default 0.3. In this simplified neuron model the signal spreads through the local motion detectors but never reaches the escape pathway, so this setting changes what you see, not how the fly plays. Set it to 0 to confirm.

What is this?

Each tick the server counts spikes from the 656 left-side and 648 right-side descending neurons, takes right minus left, and smooths that with a leaky sum that keeps 70% of its value from tick to tick. Motor gain multiplies the smoothed value into a paddle command between -1 (full speed up) and 1 (full speed down). Range 0 to 5, default 0.5. Low values make the fly sluggish; high values make it twitchy and prone to overshooting the ball.

Real: 166,700 neurons and 25.6 million connections from the MaleCNS v1.0 connectome, stepping live with state carried between frames, and learning through its own dopamine neurons. The ball is painted onto the fly's lamina (retina) columns and onto its looming detectors (LC4, LPLC2) on the side the ball is on. Left-side descending neurons firing move the paddle up, right-side down. The shortcuts: the link from retina image to looming detectors, and the diffuse dopamine reaching the paddle pathway, are computed by this page, because the simplified neuron model cannot carry either through the fly's own circuits.
